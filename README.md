Проект: Доработка сайта интернет-магазина «Переделкино»
Цель: автоматизировать оформление и обработку онлайн-заказов: сократить время обработки на 70%, снизить отмены на 50%, поднять конверсию на 20%.

Результат: документ с требованиями к решению — 6 бизнес-требований (SMART), 12 User Stories, 4 Use Case, описание архитектуры (API склада, SMS/email-уведомления, личный кабинет, промокоды, автозврат), 15 критериев приёмки, 12 рисков и ограничений, пользовательская инструкция.

Инструменты: BPMN, UML (Use Case, классы, объекты), CJM, Figma.
